A modern, high-performance, interactive personal portfolio website for **Kacho Zuhaib Hassan**, an **Odoo Developer | ERP Developer**.

Positioned specifically for Odoo partners, technical leads, HR managers, recruiters, and clients seeking specialized ERP development, custom Odoo modules, business workflows, and integrations.

---

## 🌟 The Core Visual Concept: "The Odoo Journey"
Instead of a generic developer template, this portfolio is built around **The Odoo Journey** — an interactive 3D road that connects each milestone in Kacho Zuhaib's professional path:
- **Interactive 3D Executive Car**: A modern sedan with an obsidian finish, realistic headlights/taillights, dynamic steering, rolling wheels, realistic contact shadows, and an authentic Odoo purple brand accent.
- **Curved 3D Roadway**: A Catmull-Rom spline with glowing curbs and dashed center lines that weaves gracefully between alternating content cards.
- **Destination-Based Direct Navigation**: Clicking any section (such as *Projects* or *Experience*) animates the 3D vehicle along the curved route to that exact destination, smoothly scrolling the viewport in lockstep.
- **Scroll Synchronization**: The car responds naturally to visitor scroll progress.
- **Accessibility & Reduced Motion**: Includes a built-in motion toggle (`aria-pressed`) and respects `prefers-reduced-motion`.

## 🛠️ Technology Stack
- **Three.js (r128)** — Offline local bundle for procedural 3D car, dynamic roadway, and lighting.
- **GSAP (3.12.5)** — Offline local bundle for smooth path interpolation and synchronized scrolling.
- **Vanilla HTML5 & Modern CSS3** — CSS custom properties, glassmorphism, responsive grid, and zero build tool overhead.
- **Semantic SEO & Schema.org** — Rich JSON-LD Person schema, OpenGraph tags, and high-contrast accessibility.

## 🚀 How to Run Locally

### Option 1: Python HTTP Server (Recommended)
From this project directory, run:
```bash
py -m http.server 8000
```
Then open your browser at:
```
http://localhost:8000
```

### Option 2: Direct File Open
You can also directly open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).
